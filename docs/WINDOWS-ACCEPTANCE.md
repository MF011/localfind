# Проверка Windows перед выпуском

Статус runtime-проверки: НЕ ВЫПОЛНЕНА. Windows .exe и NSIS собраны в Linux;
состав и целостность пакета проверены без запуска. Проверка компиляции x86_64-pc-windows-gnu в Linux
не подтверждает работу WebView2, системных диалогов, Проводника и уведомлений NTFS.

Ручная проверка Windows 11 x64 под обычным пользователем:

- Первый запуск, выбор всех локальных дисков; исключение сетевых и оптических.
- Папки с кириллицей, пробелами, Unicode и путями длиннее 260 символов.
- Изменение, перемещение и удаление файлов/каталогов при открытом поиске.
- Недоступный USB-диск сохраняет результаты с отметкой; подключение восстанавливает обход.
- Нет скачивания OneDrive placeholders, нет циклов junction/symlink.
- Нет UAC-запросов при обычном поиске; отказ доступа отражается в состоянии расположения.
- Низкий приоритет worker-процессов и background thread виден в системных средствах.
- Pause/cancel завершают Python и Tesseract; Resume возвращает задачи в очередь.
- Открытие файла и выделение в Explorer, путь с пробелами, кавычками, Unicode.
- Текстовый просмотр не исполняет HTML, скрипты и Office-макросы.
- Масштабы 100%, 150%, 200%; клавиатура, контраст обеих тем, экранный диктор.
- Перезапуск после принудительного завершения, повреждённые/защищённые PDF.
- Удаление расположения удаляет результаты текста/OCR; исходные файлы остаются.
- Проверка реальной частной ACL папки LocalAppData, отсутствия сетевых запросов.
- Установка/удаление NSIS под обычным пользователем, офлайн-запуск с компонентами.
- Подписать или явно обозначить отсутствие подписи; проверить SmartScreen.

Standalone-поставка Python, Tesseract, языков и WebView2 пока не подготовлена.
Текущая конфигурация NSIS упаковывает приложение и worker-скрипт, а не Python/OCR.
Без внешних компонентов работает поиск имён; извлечение сообщает понятную ошибку.
Рабочий сценарий для разработки — scripts/windows-dev.ps1 после README setup.
