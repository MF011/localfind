# Согласованный объём

Windows 11 x64, русский интерфейс, локальная работа без аккаунта и сервера.
Индексировать доступные фиксированные и съёмные локальные диски, с возможностью
выбора папок и исключений. Сетевые пути добавляются явно. Не загружать облачные
заглушки, не обходить reparse points/символьные ссылки, не повышать права.

Уточнение пользователя: использовать доступные ресурсы на самом низком фоновом
приоритете. UI и поисковые запросы остаются обычного приоритета. Ограничения
памяти, числа процессов и размеров документов необходимы даже при низком CPU
приоритете. Отсутствует искусственное ограничение скорости индексирования.

Включено: имена/пути, фильтры, PDF/DOCX/XLSX/PPTX/TXT/MD/CSV, фразы,
контекст, PDF-страницы, листы и ячейки, OCR rus+eng, локальный кэш, очередь,
пауза/отмена/повтор, безопасный текстовый просмотр, открытие и Проводник.
Формулы Excel и сохранённые результаты различаются; пересчёта нет.

Исключено: семантический/визуальный поиск, похожие изображения, дубликаты,
лица, чат, генерация, облачная обработка, плагины, векторные базы.
DOC/XLS/PPT, USN/MFT и исправление раскладки — будущие этапы.

GO разрешает локальную разработку; публикация и отправка частных данных не разрешены.

## Этапы и критерии

A: сохранение папок, доступный во время обхода поиск имён/путей, открытие,
пауза, удаление папки с её данными, сверка изменений и недоступные диски.
B: извлечение поддержанных форматов, фразы, подсвеченный контекст,
безопасный просмотр без исполнения содержимого.
C: OCR отдельных страниц, кэш по версии/настройкам/содержимому,
управляемые процессы, состояния ошибок и повтор.
D: измерения p50/p95, пропускная способность и размер индекса, восстановление,
проверка Windows, сборка установщика и лицензий.

Каждая возможность считается подтверждённой только в проверенной среде.
Цель: p95 <100 мс для имён на прогретом индексе 100 000 файлов.
Предварительная цель текстового поиска: p95 <250 мс на том же наборе при
документированном объёме текста. OCR: измерять страницы/мин и CER отдельно;
универсального SLA для OCR нет. UI не блокируется очередью.
